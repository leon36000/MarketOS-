# C12 — Claude Code Execution Contract

## Objective
Implement an exact provider registry, task-weighted premium Model Council, selective temporal memory and isolated recursive-improvement laboratory without granting models financial authority.

## Required surfaces
`runtime/providers`, `runtime/council`, `runtime/memory`, `runtime/improvement`, `runtime/model_adaptation`, tests and private benchmarks.

## Test-first sequence
1. Unpinned model aliases, hidden retention terms or secret readback must fail.
2. Council members commit blind answers before seeing peers; equal vote is rejected.
3. Task weights derive from private OOS benchmarks and correlated errors are penalized.
4. Future, superseded, poisoned or unvalidated memories cannot enter a historical/current context as fact.
5. Winning bad decisions and losing good decisions cannot be mislabeled from PnL alone.
6. Champion and evaluator hashes remain immutable during an improvement tournament.
7. Candidates cannot read hidden holdouts, secrets, broker routes or active risk policy.
8. Improvement output is a signed proposal only; initial human and gate approval remain mandatory.

## Qualification boundary
Provider catalogs, council marginal value, memory benefit and recursive-improvement safety/value require real benchmarks. Local contract fixtures do not select a provider, model, backend or method.

## Rollback
Freeze writes and candidate generation, revoke temporary credentials, restore registry/policy versions, preserve raw/negative evidence and prove champion/evaluator hashes unchanged.
