# C8 Multi-Scale Features

Every derived feature records its input observations, economic and knowledge cutoffs, window, sampling rule, missing-value rule, adjustment policy, code/configuration hash and output hash.

Features describe patterns rather than causal mechanisms. They are compared with simple baselines, temporal holdouts, multiple-testing controls, regime stability, implementation cost and abstention.

Late observations, corrections, event adjustments and calendar changes create new versions. Historical experiment inputs are not overwritten.

Cross-frequency joins require explicit availability and alignment rules. Unsupported extrapolation produces `NO_SIGNAL`.
