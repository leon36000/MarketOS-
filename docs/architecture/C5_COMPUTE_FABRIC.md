# C5 Compute Fabric

Each node publishes a signed, expiring inventory. Hardware presence, driver readiness, SDK readiness, diagnostics and workload qualification are distinct states.

Each workload declares precision, determinism, resources, data rights, locality, deadline, cost, checkpoint and fallback. Hard constraints and numerical qualification are checked before performance or price.

Standalone cgroups and CPU affinity are the baseline. Slurm, K3s, Dask, Ray, MPI and UCX are role-specific candidates. Logical scheduler labels do not prove physical isolation.

Selection is per workload and node. There is no global vendor winner. Accelerated numerical paths retain a tested CPU reference fallback.
