# C7 — Valuation Distributions

Valuation is a family of scenario models, not a single authoritative number. Candidate methods include discounted cash flow, residual income, dividend models, relative multiples, asset-based methods, sum-of-parts and contingent-claim models.

Each run records assumptions, cash-flow and discount-rate distributions, terminal-value treatment, currency/FX policy, output distribution, sensitivities, model risk, data quality and abstention reason.

Methods must agree on identity, period, units and point-in-time inputs before comparison. A narrow result from fragile assumptions is not presented as high confidence.

Outputs are stress-tested for growth, margins, reinvestment, financing, dilution, rates, FX, commodity exposure and terminal assumptions. Model disagreement is retained rather than averaged silently.

The system abstains when the filing history is incomplete, scenarios are unstable, accounting quality is degraded, required rights are missing or uncertainty dominates the useful range.
