# C4 — Durable Workflow and Visual Tool Boundary

Temporal is a candidate for long-running onboarding, repair, reconciliation, settlement, evaluation and incident workflows. It is excluded from tick processing, immediate risk, wire encoding and low-latency routing. External effects occur in retry-safe activities with business idempotency and reconciliation.

Tool integration follows API/FIX → official SDK → typed tool/MCP → signed file exchange → DOM/accessibility automation → visual computer-use. Holo is a last-resort sensor/actuator, never financial authority.

Visual sessions use disposable browsers or VMs, restricted identities, allowlisted networks, quarantined downloads and no model-visible broker secret. Typed intent, independent pre/post verification, screenshot/DOM/video hashes and structured reconciliation are mandatory. V5 live GUI execution remains structurally blocked.
