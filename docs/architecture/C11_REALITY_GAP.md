# C11 — Reality-Gap Evaluation

Reality-gap evaluation compares more than marginal return histograms. It measures volatility clustering, tails, spread/depth, order-flow intensity, cancellations, imbalance, queue behavior, impact, latency, cross-asset transmission and response to controlled interventions.

Metrics are reported by venue, asset, liquidity, session and regime. A world can pass one family and fail another; no aggregate score hides material failure. Failure maps and abstention conditions are first-class outputs.

Generative models are tested for memorization, nearest-neighbour leakage and impossible state transitions. Agent-based models are tested for exchange invariants and sensitivity to agent composition. Macro scenarios retain structural assumptions and competing propagation models.

Synthetic realism cannot close financial promotion gates. It only determines which research uses are permitted.
