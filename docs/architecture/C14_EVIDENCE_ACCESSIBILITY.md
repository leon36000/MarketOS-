# C14 — Evidence UX and Accessibility

Every material claim can expose source, as-of and first-seen times, freshness, real/synthetic/proxy classification, confidence, uncertainty, contradictions, version, gate state and evidence link.

Profit, loss or a green indicator is not synonymous with a good decision. Portfolio and experiment views separate forecast, risk, cost, execution, outcome and attribution.

Status cannot rely on colour alone. Keyboard operation, visible focus, labels, error identification, target size, responsive reflow, reduced motion and screen-reader semantics target WCAG 2.2 AA.

Charts provide textual summaries, exact values, units and table alternatives. Dense expert views offer progressive disclosure without hiding warnings or uncertainty.
