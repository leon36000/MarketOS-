# C6 Numerical Truth Kernel

Authoritative cash, quantity, ticks, fees, accounting and hard limits use scaled integers or controlled decimals with explicit units.

The CPU FP64 reference uses deterministic algorithms, stable reduction order and content-addressed diagnostics. Parallel paths merge stable chunk identities. Accelerators are compared to this reference and cannot define their own tolerances.

Differential evidence includes absolute, relative and ULP error, distribution/tail distance, determinism and whether a portfolio, risk or order decision changes. A candidate can pass average error yet fail on a boundary decision.

Covariance diagnostics expose original rank, spectrum and condition. Repair, shrinkage or clipping is explicit and preserves original and modified results. Monte Carlo pins algorithm, seed, per-chunk streams, reduction order and checkpoint identity.

NaN/Inf, hidden fast-math and nondeterministic reductions cannot enter canonical evidence. CPU fallback is continuously tested.
