# C5 Node Pack, Cloud and FPGA Boundary

A temporary bootstrap credential may install a least-privilege node service and enroll mTLS; it is then removed. The signed inventory records topology, devices, runtimes, raw probe hashes, health and expiry. It never auto-installs drivers, firmware, BIOS changes or FPGA bitstreams.

Workloads use immutable images, cgroups/affinity, bounded scratch, allowlisted networks, evidence hashes and checkpoints. Stale health, incompatible precision, missing fallback or unknown data rights block execution.

Cloud profiles require approved region and rights, immutable images, cost and transfer limits, checkpoint/restore, automatic expiry, destruction receipt and local revalidation. Cloud is excluded from critical live paths.

FPGA progresses from Python and optimized CPU through kernel-bypass/SmartNIC, simulator, development card, shadow and bounded canary. Purchase is forbidden until measured latency has economic value after development, verification and maintenance costs.
