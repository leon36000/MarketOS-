# C6 Probability, Calibration and Abstention

A proposal exposes predictive return/loss, epistemic and aleatoric uncertainty, regime probability, execution-cost distribution, tail/liquidity risk, capacity and probability that net edge remains positive.

Calibration is measured out of sample and by regime with reliability, Brier/log loss and interval coverage. Recalibration uses temporally valid calibration sets, creates a new version and never rewrites prior decisions.

NO_TRADE is first class. The system abstains for stale data, out-of-distribution state, weak calibration, correlated errors, cost uncertainty, capacity breach or risk veto.

Bayesian and conformal methods remain candidates. Priors, likelihood, convergence, posterior checks, exchangeability and sensitivity are explicit evidence rather than assumed guarantees.
