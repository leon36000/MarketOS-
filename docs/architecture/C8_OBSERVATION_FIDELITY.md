# C8 Observation Fidelity

The detail ladder is explicit: aggregated intervals, top observations, aggregated depth and individual message sequences.

A lower-detail dataset cannot validate behavior that depends on a higher-detail dataset. Every experiment records source schema, sequence recovery, clock quality, detail level, assumptions and blind spots.

Outputs report uncertainty, latency, capacity and divergence as distributions. Simulated and observed outcomes remain separately classified.

Higher-detail data is admitted selectively only when aligned samples demonstrate stable incremental value after rights, storage, compute, engineering and operational cost.
