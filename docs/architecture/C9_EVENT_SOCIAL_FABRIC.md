# C9 — Real-Time Event and Social Fabric

Every event preserves source identity, source event/sequence ID, publication time, receive time, durable persistence, strategy availability, raw hash, edits/deletions, author identity, claims, entities, novelty, velocity, credibility, manipulation risk, corroboration, rights and retention policy.

## Fast path

A small local classifier plus deterministic rules may alert, collect more evidence, pause a dependent path or reduce exposure under a pre-authorized policy. It cannot increase exposure, alter limits or bypass portfolio/risk controls.

## Deep path

The deep path checks primary sources, builds a point-in-time context, resolves entities, compares independent sources, tests contradictions, estimates uncertainty and exposure transmission, then submits only a typed proposal through normal portfolio and risk gates.

## Stream hierarchy

X filtered streams and lower-latency enterprise streams are separate products with separate rights/cost gates. Bluesky authenticated firehose or a verified backfill/live-cutover service is preferred for research-grade capture; simplified unauthenticated JSON streams are discovery tools unless independently verified. Discord, Telegram, Reddit, RSS and licensed news feeds use source-specific adapters and permissions.

Reconnects, sequence resets, duplicates, edits, deletions, account compromise, recycled old stories, coordinated manipulation and missing media are mandatory tests. A single uncorroborated item can accelerate investigation but never becomes financial truth.
