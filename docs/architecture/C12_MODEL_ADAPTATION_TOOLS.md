# C12 — Model Adaptation and Tool Authority

Prompting, retrieval, tool use, LoRA and continued pretraining are compared in that order of cost and irreversibility. Financial adaptation is admitted only when temporally valid private benchmarks show marginal value over general models and deterministic tools.

Training data records rights, source cutoffs, deduplication, contamination checks, model/card hashes, evaluation and rollback. A specialized model remains advisory and can abstain; it cannot replace numerical, data, risk or execution authorities.

Tool integration follows API/protocol, typed MCP/tool, CLI/file exchange and isolated GUI fallback. Tool results include units, provenance, versions and diagnostics and are independently validated before becoming evidence.
