# C13 Primary Source Ledger

Accessed 2026-08-13. Primary sources guide control design; they do not certify MARKET-OS.

- SEC Rule 15c3-5 adopting release: https://www.sec.gov/rules/final/2010/34-63241.pdf
- SEC market-access risk-control FAQ: https://www.sec.gov/rules-regulations/staff-guidance/trading-markets-frequently-asked-questions/divisionsmarketregfaq-0
- NIST SP 800-61 Rev. 3: https://csrc.nist.gov/pubs/sp/800/61/r3/final
- NIST Cybersecurity Framework 2.0: https://www.nist.gov/cyberframework
- OAuth 2.0 Security BCP, RFC 9700: https://www.rfc-editor.org/rfc/rfc9700
- OWASP ASVS project: https://owasp.org/www-project-application-security-verification-standard/

Regulatory controls for brokers inform architecture but do not make a private system compliant or safe. Broker terms, account permissions and jurisdiction-specific obligations require written verification.
