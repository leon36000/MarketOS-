# Requirements

`REQUIREMENT_CROSSWALK.csv` is the reconciled 108-requirement audit baseline. Evidence counts inside individual rows describe the audit state at reconciliation time; `planning/C0_1_FINAL_RECONCILIATION.md` and `planning/PHASE_INDEX.json` are authoritative for the current count of formal execution contracts.

The repository currently contains 10 formal execution contracts: nine inherited contracts plus the C1 deployment/operability contract.

`REQUIREMENTS_INDEX.json` is the compact machine index used during validation and context assembly. The external Neon Memory Control Plane tracks the 108 reconciled requirements plus direct memory and tool-control requirements separately; its current observed total is 119. Neon remains a validated retrieval/state layer, not the canonical source of truth.
